**Warzone Eclipse** is a custom Call of Duty: Warzone client project focused on providing an extensive collection of configurable gameplay-related features.

The project is designed with flexibility, customization and performance in mind, combining different visual systems, interface options and configurable tools into one unified environment.

Our goal is to create a clean, modern and feature-rich client experience.
